Web Dashers - Quick Start

To run this on a Chromebook (or any device where opening index.html directly doesn't load textures), do one of the following:

Option 1: Run the local server (recommended)
- Extract this zip
- Open a terminal in the extracted folder (web-dashers.github.io)
- Run: python3 serve.py
- Your browser will open automatically at http://localhost:8000

Option 2: Use any local HTTP server
- python3 -m http.server 8000
- Then open http://localhost:8000 in your browser

The game will work correctly when served over HTTP. Direct file:// opening may not load textures due to browser security restrictions.
